# 示例产品

> 一句话定位：给某类人，在某个场景下，解决某个具体问题。

## 使命与愿景

| 项 | 内容 |
| --- | --- |
| 使命 | 让某件事不再靠运气和意志力 |
| 愿景 | 十年后，每个需要它的人身边都有一套属于他自己的系统 |
| 核心目标 | 跑通第一个最小闭环，验证有人愿意持续用下去 |

## 为谁解决什么

- 想改变但总是半途而废的人：缺的不是方法，是反馈
- 已经在用别家产品的人：缺的不是功能，是连续性
- 团队里的新同学：缺的不是文档，是上下文

## 关键问题（我们必须能回答）

| 问题 | 我们的答案 |
| --- | --- |
| 为什么是我们 | 因为我们盯着的是别人没当回事的那个细节 |
| 凭什么留得住人 | 用得越久，沉淀越多，换走的代价越大 |
| 钱从哪来 | 免费给完整闭环，付费去掉限制 |

## 产品边界

- 做：把一件事做透
- 不做：什么都想要，最后什么都不精
