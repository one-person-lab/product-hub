# 示例产品 · 愿景

> 十年后回头看，我们希望这件事被做成了。

## 使命与愿景

| 项 | 内容 |
| --- | --- |
| 使命 | 让某件事不再靠运气和意志力，让每个人都能系统地做到 |
| 愿景 | 十年后，每个人身边都有一个最懂他的系统 |
| 核心目标 | 做出第一个「用得越久越懂你」的产品 |

## 为谁解决什么

- 想改变又总半途而废的人：给他反馈，而不是给他方法论
- 已经在记录的人：让他的记录产生复利，而不是躺在文件夹里
- 刚接手项目的人：给他上下文，而不是一堆散落的文档

## 关键问题

| 问题 | 我们的答案 |
| --- | --- |
| 用户第一次凭什么留下 | 第一天就让他看到「它懂我」的证据 |
| 第二个月凭什么回来 | 关系变深：沉淀本身就是回来的理由 |
| 钱从哪来 | 免费给完整闭环，付费去掉限制 |

## 遗留张力

- 想做得深，就要用户持续投入；想门槛低，就不能要求太多——这两者还没找到平衡点
